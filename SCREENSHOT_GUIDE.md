## Screenshot Creation Tips

### Visual Consistency
- Use the same browser (Chrome recommended)
- Maintain consistent zoom level (100%)
- Hide browser bookmarks and extensions
- Use incognito mode for clean browser chrome
- Keep system notifications hidden

### Data Guidelines
- Use realistic but optimized data
- Avoid placeholder text like "Lorem ipsum"
- Use professional vendor/brand names
- Show variety in metrics (not all perfect)
- Include recognizable product categories

### Color and Branding
- Ensure BrandSight branding is visible
- Maintain consistent color scheme
- Use high contrast for readability
- Highlight key features with subtle annotations
- Keep Shopify's green accent color visible

### Annotation Best Practices
- Use sans-serif font (Helvetica or Inter)
- Keep text concise (max 5-7 words)
- Position annotations to not obscure data
- Use arrows sparingly and consistently
- Maintain 20px padding from edges

### Technical Specifications
- Format: PNG (24-bit with transparency if needed)
- Dimensions: Exactly 1600x900 pixels
- DPI: 72 (web resolution)
- Color space: sRGB
- File size: Under 1MB each
- Naming: Sequential numbering (01, 02, etc.)

## Tools for Screenshot Creation

### Recommended Software
1. **Figma/Sketch** - For adding annotations
2. **CleanShot X** (Mac) - For capturing and annotating
3. **ShareX** (Windows) - Free screenshot tool
4. **Photoshop** - For final touches and export

### Browser Tools
- **Window Resizer Extension** - Set exact viewport size
- **Full Page Screen Capture** - For long pages
- **Pesticide Extension** - Check element alignment

### Validation Checklist
Before submission, verify each screenshot:
- [ ] Exactly 1600x900 pixels
- [ ] No personal/sensitive data visible
- [ ] Annotations are readable
- [ ] Brand colors are accurate
- [ ] Interface looks modern and clean
- [ ] Data appears realistic
- [ ] No browser errors or warnings
- [ ] File size under 1MB
- [ ] Named correctly in sequence

## Common Rejection Reasons to Avoid

1. **Poor Quality**
   - Blurry or pixelated images
   - Incorrect dimensions
   - Low contrast text

2. **Misleading Content**
   - Unrealistic metrics
   - Features not in app
   - Exaggerated claims

3. **Technical Issues**
   - Console errors visible
   - Broken UI elements
   - Loading spinners

4. **Branding Problems**
   - Competitor logos visible
   - Inconsistent app name
   - Missing app branding

5. **Data Issues**
   - Test data like "Test Store"
   - Inappropriate vendor names
   - Obviously fake metrics
